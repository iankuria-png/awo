### Distilled taste rules
- **Show, don't tell.** Minimal copy per screen and one bold idea per surface.
- **Non-generic layouts:** bento grids, asymmetry, overlap, varied card sizes, floating elements, full-bleed moments. No stacks of identical rounded cards.
- **Motion everywhere it means something:** taps, progress, waiting, wins, the nav collapse (M1–M6 in doc 07). Make it tangible: loops, counters, bursts, morphs.
- **Human warmth:** real people (photography or quality illustration), community faces, the buddy feature.
- **Premium global craft:** benchmark against Revolut, Monzo, Wise, Duolingo, Headspace, Cash App and Nubank. Africa in substance, never decoration.
- **Avoid AI tells (D13):** cream grounds, all-caps eyebrow labels, "A · B · C" meta strings, fake 01/02/03 numbering, identical cards with the same shadow, gradient washes as decoration, arrows appended to button text.

## 6. Mistakes to avoid repeating

1. **Guessing references I couldn't see.** I assumed Pock was purple while Behance was blocked, but it's green and lime. *Always look before designing; say so when you can't.*
2. **Changing what was liked.** Round 2 recoloured B (teal night) and it got worse. *Keep liked elements stable; change only what's criticised.*
3. **Weak character design.** The Ola droplet with blush cheeks read as generic clip art. *Characters need real craft: a distinctive silhouette, expressive but minimal features, a considered palette.*
4. **Static "interactive" screens.** The Learn path was a picture of interactivity. *Build real state machines with `setState` and `is_interactive: true`.*
5. **Text-heavy layouts** (Direction C). *Cut copy; let visuals carry meaning.*
6. **AI-made tells** in Round 1 (cream ground, all-caps eyebrows, middle-dot meta strings). See D13.
7. **Faceless illustrated people** were a workaround for blocked photo sites. They're acceptable as placeholders but not the bar. *Use real photography (Unsplash direct image URLs work; an Unsplash API key would unlock search) or a clearly briefed illustration style.*
8. **Very long turns with no visible output.** *Publish two to four boards at a time, with a one-line status in between.*
9. **Context burn.** Big artboards (10–25 KB each) and many screenshots filled the context. *Delegate crawling to subagents, reuse snippets, and don't re-read large files you just wrote.*

## 7. Technical notes and gotchas

### The Design canvas (artifact type "Design")
- The canvas URL is `https://claude.ai/artifact/KxjTM3X7VQiEButw4QNiV9`. **Never create a new canvas**; publish to this `url`.
- Files live under `project/`. The index is `project/canvas.json`, with one `project/<Name>.dc.html` per artboard.
- **Before changing the index, `read` it** (it may have editor-added keys such as `attachments` and note `w`). Keep every existing key, and add `{"id":"r3","name":"Round 3"}` to `pages`. Give each new board `"page":"r3"` and each new note `"page":"r3"`. Optionally set `launch: {"view":"canvas","page":"r3"}`.
- Publishing: write files into a scratchpad folder at `project/...`, then `Artifact publish` with `url`, `root` (the folder), `file_path` (one file) and `files` (the others). Only send new or changed files.
- `.dc.html` rules that fail silently:
  - Keep `<script src="./support.js"></script>` exactly.
  - Give the root element a fixed size equal to the board's `w`/`h`.
  - Always include the `<script type="text/x-dc" data-dc-script data-props='{"$preview":{...}}'>` block with `class Component extends DCLogic { renderVals(){...} }`.
  - Close every tag, and use inline styles.
  - `@keyframes` go in the `<helmet><style>`; fonts come only from a Google Fonts `<link>` in the helmet.
  - Holes are `{{path}}` lookups only, never expressions. State comes from `this.state` / `this.setState`. Use `<sc-if value="{{x}}" hint-placeholder-val="{{ false }}">` and `<sc-for list="{{xs}}" as="x" hint-placeholder-count="3">`.
  - Style holes are OK for state-driven values (e.g. `border: 2px solid {{a.bd}}`).
  - No emoji, and use real `<button>`/`<a>`/`<input>`+`<label>` elements.
- Interactive boards need `"is_interactive": true` in the index. Links between boards use `<a href="Other.dc.html">`.
- Title notes (`kind: "title1"`) sit at least 223px above their row. Leave 80px between frames in a row and about 420px between rows (to fit titles).
- Images: `Artifact publish` with `url` + `file_path` + `asset: true` returns `/_blob/<id>`; use it in `<img src>`. Don't use `data:` URIs.
- The type's rules say *don't verify renders unless Ian asks*. **Ask Ian at the start of Round 3 whether he wants Claude to self-check.** For marketing PNGs, local HTML → PNG rendering is a legitimate way to see the output.
- Existing board files (read with `Artifact read` + `path: "project/<file>"`):
  - Round 1: `Main` (A system), `A-Home`, `A-Profile`, `B-System`, `B-Home`, `B-Profile`, `C-*`
  - Round 2: `R2-Brand-Wordmark`, `R2-Brand-Icons` (16 hand-drawn icon paths plus the wobble filter), `R2-Motion` (keyframes library: ripple, count-up via `@property --n`, badge burst, glass nav), `R2-A-Welcome`, `R2-A-Starter` (interactive single-select pattern), `R2-A-Home` (`sc-for` mood chips pattern), `R2-B-Mascot`, `R2-B-Ask`, `R2-B-Learn`, `R2-D-Welcome`, `R2-D-Goals` (interactive multi-select pattern), `R2-D-Home` (portrait SVG set P1–P6).
- Canvas comments and republishes can wake the session that published last. A new session should re-arm by reading or publishing the canvas.

## 9. Product decisions to keep in mind while designing

- The core loop: DIVA profile → governed interpretation → one next step → 30-day check-in → progress.
- **DIVA results are never gamified:** no confetti, no mascot, and never a credit-score look. Celebrate effort (lessons, actions) instead.
- **Evidence confidence** is shown separately from the score.
- **Provenance labels:** *Reviewed by AWO* · *AI-assisted* · *Sample*. All numbers and interpretations are **sample** content and must be labelled.
- Tier names (Bronze/Silver/Gold/Platinum) are open (D-022). Ideas floated: *Source → Stream → River → Ocean*, *Seed → Sprout → Bloom → Grove*.
- The AI (Ola / Ask) explains, finds, rewords and flags scams. It never scores or advises.
- Stokvels, chamas and susus appear as real instruments. Currencies are locale-formatted (`R 12 500,00`).
